# Brief Explorations in LLM Value Rankings
Tim Hua

## Commands for replicating core results
Download Zhang et al. (2025) data:

```bash
hf download jifanz/stress_testing_model_spec \
    --repo-type dataset \
    --include "data/all_models*" \
    --local-dir raw_data/ 
```

Calculate value rankings:

```bash
uv run python bt_rank_values.py \
    --parquet-glob "raw_data/data/*.parquet" \
    --sample-frac 1.0 \
    --output-csv "processed_data/bt_value_scores_full.csv" \
    --metadata-csv "value_data/labeled_topk_values.csv"
    --seed 42
```

(Include the aggregate flag to use the aggregated values sourced from merged_label_values.csv)

Calculate out of sample validation for ranks

```bash
uv run python bt_rank_values.py \
    --parquet-glob "raw_data/data/*.parquet" \
    --validate \
    --n-bootstrap 50 \
    --test-frac 0.1 \
    --min-value-comparisons 5 \
    --min-high-conf-comparisons 30 \
    --seed 42 \
    --validation-output-csv "processed_data/validation_results.csv"
```

Generating the two figures used in the lesswrong post

```bash
uv run python generate_malovent_dashboard.py
uv run python generate_correlation_heatmap.py
```

Running the petri validation: 

```bash
./run_parallel_petri.sh sample_minirun.csv --output sample_run1.csv --logs-dir minirun
```

## Information on data

value_data/labeled_topk_values.csv contains value labels for values that appear at least 31 times in the dataset (generated by Gemini 3)
